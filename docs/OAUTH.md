# 通用只读 OAuth 接入（T41 已验收）

用户决定暂用 devtest IP＋端口，不绑定客户端厂商，模型由外部 Agent 提供。REST 与 MCP 使用相同空间授权；此实现不增加模型、向量库或业务运行依赖。rc.14已部署，发行者为 `https://8.153.19.221`，默认HTTPS端口443。正式域名上线延期。

固定发行者由 `JUANZHAN_PUBLIC_URL` 配置为 HTTPS origin，测试允许 loopback HTTP；禁止从请求 Host 推断发行者。未配置时发现、注册和令牌端点返回404，原手动 Agent Token 保持可用。

协议采用授权码＋强制 S256 PKCE、精确注册回调、RFC8707 resource 绑定、动态客户端注册、令牌刷新与撤销。资源标识统一为 `{origin}/api/v1/agent/mcp`，也代表同一只读 REST 文档资源。支持公共客户端 `none` 和机密客户端 `client_secret_basic`/`client_secret_post`。不抓取远程客户端元数据，不接受任意文件或网络资源作为文档输入。

浏览器访问 `/oauth/authorize`，登录后通过 Cookie＋CSRF 的 `/api/v1/oauth/requests` 验证请求，并让管理员勾选空间。`/api/v1/oauth/authorize` 消费该会话绑定请求，返回经过校验的回调地址。回调携带 `iss`、原 `state` 及一次性 `code`，或 `access_denied`。客户端必须校验 state 和 iss。客户端名称由注册者声明，界面同时显示真实回调地址。

授权请求10分钟、授权码2分钟、访问令牌1小时；支持刷新时授权最长30天。刷新轮换访问令牌及刷新令牌，旧访问令牌立即失效；重用旧刷新令牌撤销整个授权族。手工撤销 Agent Token、删除客户端或管理员重置密码均撤销已有授权；密码重置和恢复也清理待处理请求及授权码。空间范围不能通过刷新扩大。

新迁移 `0013_oauth.sql` 增加客户端、会话请求、哈希授权码、授权族、刷新重用记录和端点速率计数。秘密仅在注册/签发响应出现，数据库只保留摘要。授权族关联原 `agent_tokens`，权限验证同时检查父授权到期和访问令牌到期；人工 Token 不受 OAuth 配置影响。

请求体16KiB、最多20个表单字段；注册10次/分钟，其余公共写端点60次/分钟；最多1000客户端/请求/授权码/凭据，最多50个授权空间、每授权族最多1000次刷新。客户端秘密和令牌不写日志或 URL。公网TLS与真实通用客户端验证见AGENT-INTEROP，不宣称所有厂商账户兼容。

接口契约见 [OAuth OpenAPI](reference/oauth-openapi.json)，主契约0.4.31引用扩展，共85路径。最终OAuth/认证/原Agent定向35项、通用REST客户端6项与真实浏览器授权1项通过；完整后端595项通过，后加的REST/导入契约及恢复/会话隔离另行专项通过，不重复累加为一轮完整测试。候选安装/升级/恢复、外部模型及公网TLS已实测，见TESTING/DEVTEST。
