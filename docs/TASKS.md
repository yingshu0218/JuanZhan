# 开发任务与验收

完整 34 项拓扑路线保留在 [V0.4 Roadmap](reference/archive-roadmap-v0.4.md)，所有 T01～T34 当前都不能标为生产完成。原型独立于该完成状态。

## 首轮 M0（按依赖）

| 顺序 | 任务 | 完成证据 |
|---|---|---|
| 1 / T01 | 项目分层、明确技术选择、配置/日志、Archive+Converter Compose 骨架 | 两服务可启动；健康检查与配置说明；无伪业务能力 |
| 2 / T02 | SQLite 连接/迁移执行器，接入 V0.4 DDL | 空库/重复启动；FK ON、WAL、非法关联失败 |
| 3 / T03 | 会话/CSRF/API Token 与统一错误体，先补鉴权操作契约 | 未授权读写拒绝、无 CSRF 拒绝、Token 撤销 |
| 4 / T04 | 存储抽象、流式落盘、hash/size、不可变原件 | 中断无半成品引用，失败恢复可测 |
| 5 / T05 | Space/Folder/Tag/DocumentType CRUD | 防环/重名/跨空间拒绝 |
| 6 / T06 | Document/Revision/Event 事务与软删除 | ID 稳定、版本递增、审计可追溯 |
| 7 / T07 | SQLite Job、worker、恢复/幂等/有限重试 | 重启不丢任务、上限生效、重复运行不重复产出 |

用户偏好一 agent 一目录，不因路线图可以并行就启动多 agent 写同目录。

## 最新 UI 任务覆盖

T26 详情外壳就应以结构化视图为默认，未解析时展示真实状态，不先强制原件。T29 的旧“四 Tab”任务改为“结构化正文与元数据详情 + 关联原件预览 + 历史/任务入口”；不改 T23 内容/字段的来源和确认规则。新增 UX-15～18 见 PRD。

## 每个任务交付要求

实现、契约/迁移差异、真实集成测试、运行步骤和 STATUS 更新一个切片提交。不得仅用假数据 UI 宣布该后端任务完成。遇到原始文件矛盾记录缺口并提出最小兼容修复。详细任务/验收映射以原始 Roadmap 为完整清单。
