## ADR-015 · 2026-10-16 · T01/T02 实施选择

在用户授权开始开发后，沿用既有推荐，生产骨架采用 Python 3.12 + FastAPI；
生产目录为 services/juanzhan，参考原型保留原位。前端后续沿用 React，不另引入 Vue。
当前使用标准库 sqlite3 和显式 SQL 迁移，不引入 ORM；uv.lock 固定依赖，容器使用带哈希的 requirements.lock。
Archive/Converter 共用构建定义但使用独立进程、卷权限与入口；Converter 不接触业务数据库。
服务仅声明实际能力，解析未实现；Archive 业务认证在 T03 补契约后实现。
健康检查作为内部运维接口，补入 Archive OpenAPI，不构成公开业务 API。

## ADR-016 · 2026-10-16 · T03 认证实施选择

用户授权继续开发后，补齐 OpenAPI 的五组 auth 路径，再实现单管理员认证。
管理员仅由本地 CLI 初始化/重置，无默认密码、无匿名注册；密码使用带随机盐 scrypt。
会话与 API Token 使用 256 位随机值，数据库仅保存 SHA-256 摘要，重置密码撤销全部登录凭据。
Cookie 使用 HttpOnly/SameSite=Strict，Secure 默认开启；登录同样校验匿名会话 CSRF，成功轮换会话。
选择固定八小时管理员会话、十分钟匿名会话；API Token 默认 90 天、最多 365 天。
API Token 管理仅限 Cookie 会话且写操作校验 CSRF；Bearer 不可增发 Token。
全局五次失败/分钟登录限流、1000 匿名会话容量为本轮默认边界，后续按实测调整并同步契约。
这是实施决策，不增加多用户、邮件找回、细粒度角色或 LLM 等产品范围。

## ADR-017 · 2026-10-16 · T04 存储实施选择

本地托管对象采用 SHA-256+size 内容寻址；随机临时文件与最终对象放同一 managed 卷。
以文件 fsync + 不覆盖目标的原子硬链接 + 目录 fsync 发布，不用覆盖式 replace。
重复对象重验完整性，物理去重不改变业务 Document 身份。
卷内共享/排他 flock 协调写入与临时文件恢复，启动仅清理超过一小时的普通 staging 文件。
完整孤儿对象保留，数据库感知 GC 在 T15 实现；禁止数据库失败后无条件删除对象。
显式要求调用者传入 max_bytes，不在 T04 擅自确定产品最终上传配额。
上述为实施选择；适用本地 POSIX 托管卷，不承诺网络文件系统、物理 WORM 或断电恢复能力。

## ADR-018 · 2026-10-16 · T05 分类服务实施选择

实现既有 OpenAPI 中的 Space/Folder/Tag/DocumentType 最小管理路径，扩展契约至0.4.2；
不凭空增加 Space 编辑/删除或类型硬删除。名称 NFC 展示，NFKC+casefold 比较目录/标签唯一性。
Space 名称不加现有 SQL 未定义的唯一约束。单管理员可列出全部空间，空间过滤参数可选。
目录删除先交付 only_if_empty；涉及档案迁移/回收的两种策略明确501并在 T09 接续，
不绕过尚未建立的文档事务。标签删除需解除关联并保留档案/文件，同时递增文档版本、记录事件。
类型支持停用与模板替换，校验现存字段的空间边界，不隐式删除历史值。
相关输入限制与名称规则属于本轮实施选择，已同步 API/DEVELOPMENT；不是新产品范围。

## ADR-019 · 2026-10-16 · T06 档案事务实施选择

T06 交付内部 DocumentService，供后续上传/扫描/公开路由复用，不临时发明 HTTP 创建接口。
完整落盘对象经重验后，Document/Revision/managed_objects/Event 同事务登记；Revision 只追加。
版本校验与编号分配在 SQLite 写锁内完成，更新原件不丢弃旧成功 ParseRun/人工字段/标签。
重复提示限定同空间当前或历史版本（含回收站），显式 keep_separate 保持不同业务档案。
软删除和恢复不删除文件，版本匹配的重复目标状态操作为无变更；所有过期版本拒绝409。
恢复操作补齐 expected_document_version 契约，Archive API 扩展0.4.3，公开路由接入仍属于T09。
外部档案可以软删除/恢复，但托管接管仍501并留T16；不提前宣称扫描能力或物理恢复能力。

## ADR-020 · 2026-10-16 · T07 任务执行实施选择

SQLite 持久队列采用幂等键+请求摘要、BEGIN IMMEDIATE认领、可过期租约与随机令牌围栏。
Archive worker作为独立进程容器，共用业务数据库卷，不引入第三个业务服务或消息中间件。
单worker串行任务，每个handler使用可终止的spawn子进程；默认30秒租约、60秒执行限时、3次尝试。
只对明确可重试错误自动退避，手动重试不重置预算；过期worker不能提交数据库结果。
业务数据库副作用与任务完成标记通过同连接事务提交，整体仍为至少执行一次，远程副作用需额外幂等协议。
当前只接入托管临时文件清理，不把其他未实现handler标为成功；公开查询/重试复用既有契约。
上述为可调整的实施默认值和维护边界，不是未经验证的吞吐量/多机队列承诺。

## ADR-021 · 2026-10-16 · T08 上传实施选择

新增锁定python-multipart依赖，复用Starlette受限解析器；按文件/请求/字段/头/接收时间与并发多层约束。
默认64MiB单文件、额外64KiB表单开销、60秒接收期限、每API进程两个槽位；可在环境中调整大小/期限。
MIME用有界文件头/ZIP元信息保守识别，不信任客户端声明，不展开归档或执行原件。
DocumentService增加可信同事务after_create回调，让上传的档案/Revision/审计/parse任务一起提交，
不嵌套两个写事务。201只声明原件已保存；当前parse未实现如实失败，原件不受损。
默认needs_review，显式filed在无缺失必填字段时允许；上传尚不接受文档类型或自定义字段。
默认值与嗅探边界属于本轮实施选择，不是用户已确认的最终资源上限或安全扫描能力。

## ADR-022 · 2026-10-16 · T09 公开档案状态与子树删除

复用现有档案事务，抽出共享快照/版本检查，公开输出显式字段白名单，避免路径泄露。
管理列表采取稳定排序与分页；不实现局部冒充全文检索，非空q明确501。
原件可用性与处理状态独立；托管列表仅做轻量探测，外部未验证状态新增unknown，不承诺已能读取。
目录非空删除需回传目录ID确认，扁平迁移整棵子树至根的父目录或统一无目录软删除；已有回收时间不改。
来源引用阻止删除，避免擅自更改扫描配置；目录、档案版本与审计一次提交且无文件副作用。
模板归档暂校验必填存在，遇复杂约束501留T18，不以缺省放行替代完整类型规则。

## ADR-023 · 2026-10-17 · T10 有界选择快照与围栏撤销

遵循既有202异步契约，当前批量统一进入持久JobQueue，最多100项/64KiB，不增加同步快速路径。
选择集由调用者枚举，提交必须带精确ID到版本映射，持久化后不动态扩张；超限拒绝，不静默截断。
每项savepoint隔离业务错误，成功变更/事件/逐项结果/任务完成同一租约围栏事务；中断整次回滚再重试。
复用document_events.batch_job_id及before/after快照，不新增迁移或另建撤销状态表。
最小撤销只恢复原成功项的逻辑字段，要求版本仍等于原执行后版本，避免覆盖后续人工编辑；引用失效不强制恢复。
相同原任务使用固定撤销幂等键，不支持撤销的撤销；服务端单管理员不额外模拟浏览器会话历史栈。
未实现解析/字段能力时明确501，不把排队当业务成功。上述限额和全异步是实施选择，可后续评估调整。

## ADR-024 · 2026-10-17 · T17 字段定义与模板引用

复用field_definitions/document_type_fields既有表和catalog写事务，无需迁移。key/type/space创建后API不可修改，无硬删除。
停用字段保留现存模板及历史值，禁止新增停用引用，允许原绑定调整/移除；停用不暗中取消归档必填要求。
定义配置更新不改变档案事实/版本，模板换型不清历史metadata_values；实际值/归档重新校验由T18完成。
沿用原OpenAPI开放constraints对象，当前只存储有界JSON，不新增未确认的规则词汇或假装规则已执行。
实施上限每空间1000定义（含停用）、约束紧凑JSON16KiB/深度8，有限JSON数值；配置开关不等于搜索/筛选实现。
上述资源上限属于实施选择，未来依据真实数据调整；T18需同步约束语义契约并如实拒绝未知规则。

## ADR-025 · 2026-10-17 · T18 类型值、约束与显式采纳

复用metadata_values类型列/约束与DocumentService事务，无新迁移。null删除行，false保留value_bool=0；字段全局同空间可赋值，换类型不丢历史。
新配置约束词汇按字段类型限定，稳定options={id,label}；required归模板，未知新规则422、历史未知规则501要求显式修复。
引入锁定regex以20ms匹配超时支持规则；有界模式/量词/文本/JSON上限是实施默认，未来可据真实负载调整。
Decimal普通十进制字符串×10000精确落INTEGER，固定4位输出，不接受浮点/指数，不扩大既有DDL的±9×10^16存储范围。
filed写值与完成整理重校验现模板，必填以及已存可选值均验证；失败原子回滚值/版本/审计，无变化不递增版本。
保守拒绝旧Revision/非当前成功内容候选；显式采纳才可替换人工值，带版本、来源和候选ID审计，不删除原候选。
不将候选验收夹具视为真实解析生成，批量元数据写入留独立接续，不复用简化路径绕过规则。

## ADR-027 · 2026-10-17 · T27 真实整理界面与批量恢复

单项与批量UI统一复用持久任务/逐项事务/审计，补齐restore而不另建同步写入路线；恢复保留字节与可用目录，撤销不覆盖后续修改。
选择固定ID/版本及原空间分类上下文，当前页与全部筛选结果明确区分；100份上限为既有后端边界，超限拒绝而非静默截断。
OS Files与内部拖放严格分开：前者走上传，后者页面私有令牌关联内存快照并验证同空间，只修改逻辑引用，先确认再提交。
结果保留当前页面，不宣称刷新后恢复；任务中心留T31。写请求不自动重试；关闭弹窗保留轮询及结果入口。
真实worker测试发现关闭父管道时子进程确认可能BrokenPipe；确认发送容忍关闭，事务结果与租约仍为事实来源，不改变业务完成状态。
