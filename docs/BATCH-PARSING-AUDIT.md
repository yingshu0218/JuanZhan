# 批量上传解析核查与默认OCR（T62）

2026-10-25用户要求检查批量上传结果，随后明确OCR需要默认开启，并确认散图批次使用页内文件夹引导。此决定覆盖历史ADR-036/单份与批量重解析中“默认关闭OCR”的产品默认值；Converter独立协议的默认值仍保留，Archive显式决策。

## 核查基线（修复前）

devtest共有359份未回收档案（352份在原空间，7份为既有独立验收示例）。逐个只读打开原件并校验SHA-256及字节数，359/359一致，共25796107字节；SQLite integrity_check=ok、外键错误0。未更改原件、业务字段或用户任务。

188份当前成功结果有可读正文，167份PNG的基础解析成功但未执行OCR，4份没有当前成功ParseRun（其中1份已有有效Agent分析）。持久Markdown：188份content、167份empty、4份unavailable；empty/unavailable是元信息兜底，不冒充可读正文。没有失败任务。344个queued全部为延迟GC，并非文档解析队列。

待处理170份：167 PNG、1 WebP、1旧.DS_Store、1主动取消/删除任务后保留的验收TXT。WebP当前没有本地解析支持，不虚称OCR已覆盖该格式；.DS_Store按既有排除规则拒绝重解析，但旧原件不追删。旧JSON/开发文件为此前导入记录，不因新默认规则追删。

## 实施

- Archive自动导入解析对PNG/JPEG/TIFF和PDF默认启用chi_sim+eng；PDF只识别无文字层页，普通文本/Office不增加OCR步骤。显式ocr_enabled=false仍生效，不修改独立Converter默认协议，不新增模型或依赖。
- 单份/批量重解析及待处理清单默认勾选OCR，中英文默认，保留语言选择。待处理API增加严格布尔ocr（默认true）与eng/chi_sim语言集合；非空语言要求ocr=true。
- 当前版本Agent结果优先不变；旧版本分析不覆盖当前Revision。本地OCR只是字符识别，不能描述无字图片或推断语义。
- 待处理清单返回mime_type、ocr_required、ocr_no_text；明确旧结果待识别、识别未检出文字和未知格式。OCR后仍需当前正文、Markdown与最新索引全部可用才移出，空白/无字图继续保留，不能以任务completed充当可读正文。
- 相同请求重发幂等；已有活动解析选项不一致逐项冲突，不偷偷复用非OCR任务或覆盖任务。保留原件、人工字段/标签、旧成功结果及租约围栏。
- 同次选择/拖放至少10张散图且无目录结构时，上传前提供页内“批量图片归档”：默认建议新建目录，可修改名、仍放当前目录、取消本批。阈值10是实施选择，不是用户指定的业务限制。原目录上传保留结构；混合文档批次不强行归组。
- 选择批次时固定空间/父目录。新建目录复用既有精确同名目录规则，校验名称不含分隔符；图片保持独立Document，不合并成多页原件；确认前不发上传请求，取消不建目录或档案。
