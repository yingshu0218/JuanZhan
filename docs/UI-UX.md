## 建议的详情布局（实施细节，可迭代）

- 详情标题、整理/解析/原件状态；显式示例/旧快照标识。
- 内容区按 blocks 展示标题、段落、列表、表格、图片引用，不用原 PDF 封面占据默认阅读区。
- 元数据区区分已确认业务值、程序候选、只读文件属性；每个候选有来源与可用定位。未知值显示“未提取到”。
- 关联原文件区显示原始文件名、MIME、来源别名/相对路径、Revision 与可用状态，提供“查看原文件”。
- 建议以抽屉预览原件，关闭后保留内容位置和筛选；抽屉是助手提出的具体方案，不是用户限定的唯一形式。
- “原文/提取文本”不再是默认内容的顶层二选一。查看原件是独立按需动作。
- 候选采纳与正文编辑是不同能力；正文修订/撤销具体范围未确认，不擅自增加 Office 编辑器。

## 必须设计的状态

首次解析未开始/排队、OCR 关闭、解析失败、unsupported、旧成功快照、外部来源离线、外部文件变化需新 Revision、并发字段冲突。旧正文可读不代表当前原件可下载。定位 unknown 不做跳页按钮。扫描件低置信度或表格降级应可见。
