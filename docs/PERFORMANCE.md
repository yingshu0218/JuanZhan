# T34 最小性能基线

测试日期2026-10-18（Asia/Shanghai）。入口：

```sh
UV_CACHE_DIR=/workspace/.uv-cache uv run --frozen python scripts/benchmark.py
```

默认1万/10万合成档案，每种请求1次预热+20次计时，串行单客户端，真实TCP HTTP→鉴权→公开API→SQLite/FTS，页大小20；p50为中位数，p95为nearest-rank。每次验证命中总数与SQLite完整性/外键，输出私有/tmp JSON。数据、随机管理员、端口均隔离，不访问正常数据卷。

这是合成元数据/FTS查询基线：语料通过真实分词器生成，直接写入一次性数据库；没有原件或ParseRun，不把索引状态字段当已真实解析十万份原件。seed_seconds不是上传/解析吞吐量，RSS是进程累计峰值而非单查询内存；不是多用户压力、冷缓存或OCR容量报告。真实文件路径另由release_drill演练。
