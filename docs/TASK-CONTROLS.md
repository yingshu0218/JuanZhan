# 后台任务控制与待处理文件（T60）

2026-10-25用户要求：后台任务支持批量暂停、取消、删除，未处理好的文件进入待处理清单，仅在检测到已处理后移出，处理规则沿用之前约定。

## 使用

任务中心分“后台任务”“待处理文件”两页。后台任务可逐项勾选、选择本页或当前状态筛选结果（最多1000项），批量暂停/恢复/取消/删除记录。取消和删除有页内确认。已完成任务不重新解释为暂停/取消；状态变化导致的冲突逐项返回，不抹掉其他成功操作。

删除表示取消尚未完成的任务并从任务列表移除，不物理删除jobs行、历史、审计或原件，不破坏档案/解析/批量撤销/备份引用。已知任务编号的历史详情仍可读取，并标记deleted。已经执行并持久提交的业务步骤不会撤销；要撤销业务变更仍走原撤销功能。

待处理文件按空间分页，最多选100份重新处理。它从文件当前版本的实际产物计算，不从任务数量、任务是否被删或进度百分比推断，也不提供手工标记完成/从清单移除。回收站档案不在当前清单，恢复后按实际产物重新计算。

## 处理完成的实施判据

用户要求检测真实处理状态，本轮采用已有产物的联合判据（实施选择）：

1. 当前Revision有有效Agent分析，或current_parse_run确属当前Revision、completed且text_available。旧Revision成功正文不充当新版本完成。
2. Agent正文Markdown已持久保存在分析中，或当前Revision的纯Markdown副本为content、且对应当前成功ParseRun；unavailable/empty元信息兜底不能假装正文可读。
3. document_search_state使用当前分词版本、已覆盖最新search_dirty.generation，且无索引错误。

全部满足才移出。暂停、取消、失败、未支持、任务记录删除都不会清除文件的待处理事实。当前版本已有有效成功产物时，额外失败的重试不会清空该成功结果；人工字段/标签变动若令索引变脏，文件可能暂时因索引待更新重新出现。原件是否在线仍与成功缓存是否可读独立，不把来源离线伪装成解析失败。

重新处理固定用户选中时的Revision，版本变动返回逐项冲突。沿用当前上传格式排除、Agent优先/本地兜底、按需OCR、原件保留和人工字段/标签保护。仅缺MD/索引时只补对应任务；没有Agent/本地可读正文时才重新解析，不内置模型、不自动启用OCR。不支持或扫描原件尚无可读文字时仍留在清单，需按需OCR或其他明确处理。

## 执行语义与边界

暂停/取消在同一SQLite写事务撤销lease，旧worker的进度、心跳和结果提交都会被围栏拒绝；worker下一次检查（通常不超过2秒）终止本地子进程。暂停保留原任务身份，恢复重新排队。转换可能从头开始，不承诺冻结进程或字节级断点。已提交给独立Converter的请求可能继续到它自己的资源/时间上限，旧结果不允许写入档案。

执行尝试号单调递增，以保留ParseAttempt唯一性和历史。运行中暂停补偿一次max_attempts，故不消耗原有失败重试余额；自动重试仍有限，退避指数受上限保护，暂停补偿本身也有限额。排队中暂停不增加额度。恢复解析会重新检查当前格式排除规则。

取消只终止本次任务，不关闭未来的来源/备份计划，不撤回已提交的独立后续任务；新的版本/业务变化仍可能生成新任务。显式从待处理清单重新处理会复用在运行任务、恢复相应暂停任务，或为已取消/耗尽任务建立新的明确请求。失败请求保留待处理清单，不循环无限重试。

恢复备份会保留普通暂停任务，并继续禁止恢复实例自动执行原实例备份/恢复操作；旧租约和凭据失效。任务软删除和控制历史随一致备份保存。

## 数据与接口

0020_job_controls.sql新增job_controls和job_control_events及Agent当前版本查询索引，旧迁移不变。jobs内部暂停仍使用queued配合控制表，claim排除受控记录；公开Job.status为paused，列表queued/running数量不含暂停或删除记录。删除记录只在库存隐藏；公开detail带deleted。共20迁移，无新依赖。

- POST /api/v1/jobs/control：action=pause/resume/cancel/delete，job_ids最多1000。逐项成功或error_code，控制操作幂等，状态冲突不强制覆盖。
- GET /api/v1/pending-documents：space_id可选、page/page_size，返回当前Revision、缺失原因analysis/markdown/index和当前格式排除提示。
- POST /api/v1/pending-documents/process：request_id及最多100项{id,revision_id}，逐项返回job_ids/已完成或错误。

管理员鉴权、Cookie写需CSRF；Agent凭据不获控制/全实例管理权限。Archive契约0.4.39/103路径，Converter契约不变。待处理判据基于已登记持久产物；不在每次列表轮询中重新哈希或读取整个原文件，文件完整性仍由既有下载/读取接口验证。
