托管与原地索引共存；首次目录导入以后解耦；一主 Folder 多标签；同哈希可为不同业务档案；人工字段优先；扫描/OCR异步；失败保留旧正文并标 stale；原件不可用与解析失败分开。详细数据/API规则以 reference 为准。
