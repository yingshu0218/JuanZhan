# 参考原型（保留成果）

这是 Work 中用户接受的档案库界面原型，React/Vite + Phosphor Icons，包含目录、缩略图/列表、示例搜索、原文/提取文本、元数据面板、标签/收藏、模拟导入。没有生产 API、真实解析/OCR、持久数据库。

运行：本目录执行 npm ci，然后 npm run dev。生产构建 npm run build；原有模板运行时与测试文件保留用于复现，尚不代表正式档案库架构。

## 与最终需求的差距

仍默认打开原文；最新要求“先看结构化数据，通过关联原件入口预览”未实现。元数据和正文是示例，原型路径/页码/日期不能照搬；PDF 图示中多文件夹与一主 Folder 规则冲突，以主知识库为准。

本目录代码原样迁移；未复制 node_modules、dist、临时日志、旧 ZIP 和带本地路径的内部 QA 报告。图片是生成效果图裁出的演示文档缩略图/示意图，不是真实用户档案。

父级 AGENTS.md 对知识库实施规则有效；本目录原来的模板指引另存为 TEMPLATE-INSTRUCTIONS.md，仅解释预览模板，不覆盖生产交接规则。
